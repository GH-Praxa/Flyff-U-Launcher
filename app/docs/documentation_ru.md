## Базовые функции

:::accordion[Создать профиль]

**Шаг 1 — Создать новый профиль:**
- Нажмите **«Новый профиль»** в шапке.

![Описание](create_profil/create_profil_1_ru.png)

**Шаг 2 — Ввести имя профиля:**
- Введите имя профиля и нажмите **«Добавить»**.
- Нажмите **«Закрыть»**, чтобы закрыть диалог без создания профиля.

![Описание](create_profil/create_profil_2_ru.png)

**Шаг 3 — Карточка профиля:**

Каждый профиль отображается как карточка в списке:

![Описание](create_profil/create_profil_3_ru.png)

| № | Элемент | Описание |
|---|---------|----------|
| ❶ | Ручка перетаскивания | Сортировка профилей перетаскиванием |
| ❷ | Цель Overlay | Определяет, какой профиль получает OCR-оверлеи и боковую панель |
| ❸ | Цель Саппортера | Определяет, какой профиль служит видом саппортера для CD-Таймера |
| ❹ | Режим запуска | Показывает, открывается ли профиль в режиме вкладок или окна |
| ❺ | Шестерёнка | Открыть настройки профиля |
| ❻ | Играть | Начать игровую сессию с этим профилем |

**Шаг 4 — Настройки профиля:**

Нажмите на шестерёнку ❺, чтобы открыть настройки:

![Описание](create_profil/create_profil_4_ru.png)

| № | Элемент | Описание |
|---|---------|----------|
| ❶ | Имя профиля | Изменить имя профиля |
| ❷ | Класс + имя персонажа | Выбрать класс из выпадающего списка и ввести имя персонажа. Каждый персонаж получает свой класс. |
| ❸ | Добавить персонажа | Добавить ещё одно имя персонажа (кнопка «Добавить») |
| ❹ | Использовать во вкладках | Включено: профиль можно использовать в макетах с несколькими вкладками. Выключено: профиль открывается только в отдельном окне. |
| ❺ | Сохранить | Применить изменения |
| ❻ | Копировать профиль | Создаёт копию профиля со всеми настройками |
| ❼ | Удалить | Навсегда удалить профиль |
| ❽ | Закрыть | Закрыть диалог |

Чтобы использовать профиль и во вкладках, и в оконном режиме, скопируйте его кнопкой ❻ и используйте по одной копии на режим.

**Шаг 5 — Список профилей с персонажами:**

Настроенные профили отображаются в списке с именами персонажей и иконками классов:

![Описание](create_profil/create_profil_5_ru.png)

- Каждый персонаж отображается как бейдж с иконкой класса под именем профиля.
- Фильтр по классу и поиск по имени в шапке просматривают всех персонажей всех профилей.
- Плагины (например Killfeed) используют сохранённые имена персонажей через выпадающий список.

Можно создать сколько угодно профилей. У каждого своя сохранённая сессия Flyff.
Настройки в игре не распространяются на другие сессии, как в браузере.

**Экспорт/Импорт профилей:**

![small](create_profil/create_profil_6.png)

| № | Элемент | Описание |
|---|---------|----------|
| ❶ | Экспорт | Сохранить профиль как файл `.flyffprofile` |
| ❷ | Импорт | Загрузить файл `.flyffprofile` и создать новый профиль |

Экспортированный файл содержит:

- Метаданные профиля (имя, класс, настройки)
- Cookies сессии Electron (данные входа)
- Данные localStorage (настройки игры)

Это позволяет создавать резервные копии и переносить между компьютерами.

:::accordion[Создать макет]

**Шаг 1 — Начать макет:**

Нажмите **«Играть»** на профиле с включёнными вкладками.

![Описание](create_layout/create_layout_1_ru.png)

**Шаг 2 — Выбор сетки:**

Выберите нужную сетку. При наведении справа отображается **ASCII-предпросмотр** сетки.

![Описание](create_layout/create_layout_2.png)

*Симметричные макеты:*
- **1×1** — Одно окно
- **1×2 / 2×1** — Два окна рядом / друг над другом
- **1×3 / 3×1** — Три окна рядом / друг над другом
- **1×4 / 4×1** — Четыре окна рядом / друг над другом
- **2×2** — Четыре окна в сетке
- **3+2** — Три сверху, два снизу
- **2×3** — Шесть окон в сетке
- **4+3** — Четыре сверху, три снизу
- **2×4** — Восемь окон в сетке

*Асимметричные макеты:*
- **1+2 →** — Основное окно слева, 2 боковых справа
- **1+3 →** — Основное окно слева, 3 боковых справа
- **1+2 ↓** — Основное окно сверху, 2 боковых снизу
- **1+3 ↓** — Основное окно сверху, 3 боковых снизу

Асимметричные макеты имеют **ползунок** в панели вкладок для регулировки разделения (мин. 20 % / макс. 80 %).

![small](create_layout/create_layout_slider.png)

**Шаг 3 — Назначить профили:**

Назначьте профиль каждой ячейке. Ненужные ячейки можно оставить пустыми.

![Описание](create_layout/create_layout_3_ru.png)

| № | Элемент | Описание |
|---|---------|----------|
| ❶ | Ячейки сетки | Показывает ячейки выбранной сетки. Нажмите на ячейку, чтобы назначить профиль из списка ниже. |
| ❷ | Список профилей | Все профили с включёнными вкладками. Нажмите, чтобы назначить выбранной ячейке. |
| ❸ | Далее | Подтверждает назначение и запускает макет с назначенными профилями. |

**Шаг 4 — Сохранить макет:**

Кнопка, отмеченная на изображении (в строке заголовка), открывает диалог сохранения.

![Описание](create_layout/create_layout_4.png)

Введите название макета и нажмите **«Сохранить»**.

![Описание](create_layout/create_layout_5_ru.png)

**Шаг 5 — Карточка макета в лаунчере:**

Сохранённые макеты отображаются как карточка в списке профилей:

![Описание](create_layout/create_layout_6_ru.png)

- Карточка показывает **название макета**, **количество профилей** и **миниатюру сетки**.
- **«Играть»** запускает весь макет.
- **Шестерёнка** открывает настройки (название, назначение профилей, сетка).

**Пользовательский макет (Custom):**

Помимо предустановленных сеток, опция **«Пользовательский»** позволяет создать свободный макет. В редакторе можно свободно размещать и изменять размер 1–8 ячеек на холсте.

![Описание](custom_layout_editor.png)

| № | Элемент | Описание |
|-----|---------|-------------|
| ❶ | Добавить ячейку | Добавляет новую ячейку (макс. 8). |
| ❷ | Сетка | Точность привязки при перемещении/изменении размера (1%, 5% или 10%). |
| ❸ | Ползунок | Устанавливает регулируемую линию разделения: горизонтальную (↔), вертикальную (↕) или отсутствует (—). Зелёную линию можно перетаскивать в редакторе для настройки разделения в реальном времени. |
| ❹ | Ячейки | Каждую пронумерованную ячейку можно перетаскивать и изменять размер с помощью маркеров на углах и краях. |
| ❺ | Свойства | Позиция X/Y и ширина/высота выбранной ячейки в процентах. Значения также можно ввести вручную. |
| ❻ | Удалить ячейку | Удаляет текущую выбранную ячейку. |

Перекрывающиеся ячейки накладываются — верхняя ячейка получает ввод. После подтверждения макета следует назначение профилей, как и для предустановленных сеток.

**Связанные настройки** (в Настройки / Layout):
- **Загружать вкладки последовательно** — Запускать вкладки по очереди, а не одновременно
- **Обновлять макеты при изменениях** — Автоматически сохранять изменения макета
- **Выделять активный вид сетки** — Визуально выделять текущую вкладку
- **Отображение вкладок для макетов** — Режим отображения вкладок макета в лаунчере
- **Задержка макета** — Задержка при переключении вкладок

**Связанные горячие клавиши** (в Настройки / Горячие клавиши):
- **Предыдущая вкладка** / **Следующая вкладка** — Переключение между вкладками
- **Следующее окно** — Переключение фокуса между открытыми окнами
- **Панель вкладок вкл./выкл.** — Показать/скрыть панель вкладок в окне сессии

**Мульти-окна:**

Кроме макетов можно открывать несколько независимых окон сессий параллельно. При открытии профиля с уже активной сессией запрашивается, добавить к текущему окну или создать новое.
:::

:::accordion[Горячие клавиши]

Горячие клавиши — это свободно назначаемые комбинации клавиш (2–3 клавиши), которые работают даже при активном окне игры.

**Настройка:**
- Откройте **Настройки → Горячие клавиши**.
- Нажмите на значок рядом с действием и нажмите нужную комбинацию клавиш.
- Конфликты автоматически обнаруживаются и отображаются.

![Описание](hotkeys/hotkeys_settings_de.png)

**Доступные действия:**

| Действие | Описание |
|----------|----------|

| Переключить панель вкладок | Показать/скрыть панель вкладок в окне сессии |
| Предыдущая вкладка | Переключиться на предыдущую вкладку |
| Следующая вкладка | Переключиться на следующую вкладку |
| Следующее окно | Переключить фокус между открытыми окнами |
| Сбросить CD таймер | Установить все CD таймеры на 00:00 (ожидание нажатия клавиши) |

| Калькулятор FCoins | Открыть калькулятор FCoins |
| Список покупок | Открыть премиум список покупок |

Настроенные горячие клавиши можно в любое время просмотреть через **значок клавиатуры** на панели вкладок.

## Контроллер

Лаунчер и игру можно полностью управлять с геймпада.

::youtube[fSYgnEh36-g]

Назначения сохраняются **по профилю**, так что у каждого персонажа может быть своя раскладка.


:::accordion[Настройка назначений]

Откройте **Настройки → Контроллер**.

- Выберите вверху в поле **Профиль** персонажа, чью раскладку хотите изменить.
- Кнопки разбиты на группы: **Кнопки лица**, **Бамперы и курки**, **Крестовина** и **Система и стики**.
- Нажмите у нужной кнопки **Назначить клавишу**, затем нажмите желаемую клавишу — она сохранится как целевой ввод.
- **Отвязать** убирает назначение, **По умолчанию** сбрасывает отдельную кнопку, **Сбросить всё** — весь профиль.
- В схеме контроллера можно кликнуть по кнопке или навести на неё курсор, чтобы перейти прямо к её назначению.
- **Сохранить** применяет раскладку.

Стики зафиксированы жёстко: **левый стик = движение**, **правый стик = камера**.
:::


:::accordion[Специальные действия]

Кнопке можно назначить **специальное действие** вместо обычной клавиши.

| Действие | Эффект |
|----------|--------|
| Триггер Action-Pad | Клик по кнопке действия в игровом HUD (атака/прыжок/взаимодействие) |
| Приблизить / Отдалить | Приближение / отдаление камеры |
| Предыдущая / Следующая вкладка | Переключение между открытыми вкладками профилей |
| Перезагрузить вид | Перезагрузить текущее игровое окно |
| Переключить полный экран | Переключить окно лаунчера в полный экран |
| Открыть настройки | Открыть окно настроек |
| Ringmaster (переадресация) | Ввод перенаправляется в Ringmaster |
| Клик слот 1 – 8 | Клик по откалиброванному участнику группы (см. «Выбор участников группы») |

:::

:::accordion[Action-Pad]

Для атаки используется крестовина.

**Шаг 1:** Включите в игре: Меню → Параметры → Игра → «Directional Pad» **Action-Pad**.

**Шаг 2:** Назначьте кнопке (например X) специальное действие **Action-Pad**.

**Шаг 3:** Нажмите в игре **Ctrl + Shift + F1**, чтобы запустить калибровку.

**Шаг 4:** Следующий клик в игре задаёт точку привязки для Action-Pad. Кликните по центру кнопки действия.

**Результат:** Пока Action-Pad виден, выбранной кнопкой можно атаковать ближайшего монстра.

:::

:::accordion[Modifier-Layer]

С помощью **Modifier-Layer** становится доступно больше клавиш. При активации удерживание соответствующих бамперов позволяет назначить лицевым кнопкам (у PlayStation: △ ◯ ✕ ☐) несколько действий.

- Откройте во вкладке «Контроллер» раздел **Слои модификатора**.
- Активируйте бампер как модификатор (переключатель в положение **ВКЛ**).
- Задайте для каждой лицевой кнопки альтернативное действие. «(по умолчанию)» оставляет стандартное назначение.

:::



:::accordion[Ringmaster-переадресация]

С помощью **Ringmaster-переадресации** можно управлять Ringmaster в фоновой вкладке, не переключая видимое окно.

**Шаг 1:** Во вкладке «Контроллер» в основных настройках в поле **Цель Ringmaster** выберите профиль, который будет получать перенаправленный ввод.

**Шаг 2:** Назначьте кнопке специальное действие **Ringmaster (переадресация)**.

**Шаг 3:** Удерживайте в игре кнопку переадресации → весь ввод идёт в Ringmaster. Отпустите → ввод снова идёт в основной профиль.

**Внимание:** Целевой профиль должен быть открыт и выполнен вход. Если нет — перенаправленные умения уйдут в никуда.

:::

:::accordion[Выбор участников группы]

С помощью **Name-Slot 1–8** можно назначить на кнопку выбор участника группы.

**Шаг 1:** Во вкладке «Контроллер», например, на профиле Ringmaster нажмите **Калибровать слот 1**.

**Шаг 2:** Откройте в игре окно группы (при необходимости компактную версию) и кликните по первому имени в группе.

**Шаг 3:** Назначьте кнопке специальное действие «Клик слот 1».



:::


:::accordion[Выбор иконки умения]

Чтобы с первого взгляда видеть, какое умение назначено на какую лицевую кнопку, можно задать иконку для каждой кнопки (✕ ◯ △ ☐).

- Нажмите во вкладке «Контроллер» у нужной кнопки **Выбрать иконку умения** (значок камеры).
- Найдите иконку в пикере через поиск или фильтр по вкладкам **Все / Умения / Предметы / Баффы**.
- Клик по иконке применяет её; **Shift + клик** по кнопке удаляет иконку.

**Примечание:** Пикер иконок использует кэш иконок. Для иконок необходимы **API-Fetch** (умения, при необходимости также предметы) и **CD-Timer**.

Предпросмотр лицевых кнопок можно перемещать с помощью **Ctrl + Shift**.

:::

:::accordion[CD-Timer]
- Отслеживает перезарядки умений/предметов. По окончании таймера иконка с красной рамкой просит нажать заданную клавишу.
- Для показа иконок нужны API-Fetch: "Item" + "Skill".

- Убедитесь, что CD-Timer включён.  
![Описание](cd_timer/cd_timer_1_de.png)

- В боковой панели появится вкладка CD-Timer:
![Описание](cd_timer/cd_timer_2_de.png)
- "0/0 aktiv" показывает, сколько таймеров настроено и сколько активны.
- Checkbox "Alle aktiv" включает все таймеры.
- Кнопка "Alle abgelaufen" сбрасывает все таймеры на 0:00:00 и ждёт нажатия клавиши.

- Отображение иконок настраивается: позиция X/Y, размер, число колонок.

- Нажмите "+", чтобы создать новый таймер.

- ![Описание](cd_timer/cd_timer_3_de.png)
- Галочка активирует таймер.
- Кнопка "Icon" открывает диалог выбора иконки.

- `Kills` открывает список отдельных киллов выбранного ранга.

- При удалении сразу обновляются отображение в сайдпанели и файлы истории Killfeed (`daily/YYYY-MM-DD.csv` и `history.csv`).



**Правила засчёта килла:**
Килл считается, если выполнено всё:
- Уровень не изменился (нет lvl-up/down).
- EXP выросло более чем на 0.001% (эпсилон).
- Прыжок EXP не более 40% (suspect-порог); выше — помечается подозрительным и отбрасывается.
- За последние 1500 мс обнаружена полоска HP врага (OCR). Без полоски: допускается, если прошло ≥2250 мс с последнего килла.

**Отклоняемые изменения EXP:**
- Level-up/down: килл не считается.
- EXP уменьшилось: игнорируется (шум OCR).
- Прыжок EXP > 40%: помечается подозрительным, не считается.
- Нет полоски HP и <2250 мс с последнего килла: не считается.

**Примечания:**
- OCR должен быть активен, иначе киллы не определяются.
- Статы вроде киллов/час рассчитываются по скользящему окну 5 минут.

**Time to Kill (TTK):**

TTK автоматически измеряет длительность боя с боссом — от первого удара до убийства.

*Принцип работы:*
- **Старт:** Полоса HP врага обнаружена с `текущее < макс` (бой начался).
- **Стоп:** Убийство подтверждено через определение EXP. Накопленное время боя сохраняется.
- **Пауза:** Полоса HP исчезает (напр. при снятии цели для баффа или лечения). Начинается льготный период в 10 секунд.
- **Возобновление:** Если тот же босс выбран повторно в течение 10 секунд, таймер продолжается. Время паузы не засчитывается в TTK.
- **Отмена:** Если льготный период истекает без повторного выбора босса, измерение TTK отбрасывается.

*Идентификация цели:*
- В начале боя сохраняются имя монстра и максимальные HP.
- При повторном выборе сравниваются имя и макс. HP — таймер возобновляется только при совпадении.
- Если выбран другой босс, текущее измерение прерывается и начинается новое.
- Если выбран обычный монстр, таймер босса ставится на паузу; обычные убийства продолжают считаться.

*Отображение и статистика:*
- Компактная карточка: `TTK: [последнее убийство] (Ср [среднее])`
- Развёрнутая карточка: Ср. TTK, Последний TTK, Быстрейший
- Значения TTK сохраняются покилльно в CSV-истории (столбец `TTK_ms`) и агрегируются по монстру.

*Ограничение:*
- Измерение TTK активно только для Giants, Violets и Bosses. Обычные монстры не измеряются.
- Точность зависит от частоты сканирования OCR (обычно: каждые 500–1000 мс).

---

**Источники данных:**
- Данные об убийствах берутся из CSV-истории Killfeed (`daily/YYYY-MM-DD.csv`).
- Логи дропов хранятся отдельно по профилю.
- Детали монстров (иконка, HP, ATK, лут-пул) берутся из данных, загруженных через API-Fetch.

- После загрузки обновление устанавливается при следующем перезапуске.

**Ручная проверка:**
- В **Настройки → Поведение** есть кнопка **«Проверить сейчас»**.

**Откат версий:**
- Старые версии лаунчера (начиная с 3.0.5) можно установить прямо из настроек.
- Выпадающий список показывает все доступные релизы GitHub с датой и отметкой текущей версии.
- После выбора версии она загружается и устанавливается при перезапуске.

:::

:::accordion[Отображение RAM]

В **Настройки → Отображение → «Показать использование RAM»** можно включить индикатор памяти на панели вкладок.

**Функции:**
- Показывает общее использование памяти в МБ.
- При нажатии открывается подробная разбивка:
  - Использование памяти по профилю
  - Использование памяти плагинами (приблизительно, так как общее)
  - Системные накладные расходы (лаунчер + OCR)

![Описание](ram/ram_display_de.png)
:::
