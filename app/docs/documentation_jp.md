## 基本機能

:::accordion[プロファイルを作成]

**ステップ 1 — 新しいプロファイルを作成：**
- ヘッダーの **「新しいプロファイル」** をクリック。

![説明](create_profil/create_profil_1_jp.png)

**ステップ 2 — プロファイル名を入力：**
- プロファイル名を入力し **「追加」** をクリック。
- **「閉じる」** をクリックすると、プロファイルを作成せずにダイアログを閉じます。

![説明](create_profil/create_profil_2_jp.png)

**ステップ 3 — プロファイルカードの理解：**

各プロファイルはリスト内にカードとして表示されます：

![説明](create_profil/create_profil_3_jp.png)

| 番号 | 要素 | 説明 |
|------|------|------|
| ❶ | ドラッグハンドル | ドラッグ＆ドロップでプロファイルを並び替え |
| ❷ | オーバーレイターゲット | OCRオーバーレイとサイドパネルを受けるプロファイルを決定 |
| ❸ | サポーターターゲット | CDタイマーのサポータービューとして使用するプロファイルを決定 |
| ❹ | 起動モード | プロファイルがタブモードかウィンドウモードで開くかを表示 |
| ❺ | 歯車アイコン | プロファイル設定を開く |
| ❻ | プレイ | このプロファイルでゲームセッションを開始 |

**ステップ 4 — プロファイル設定：**

歯車アイコン ❺ をクリックして設定を開きます：

![説明](create_profil/create_profil_4_jp.png)

| 番号 | 要素 | 説明 |
|------|------|------|
| ❶ | プロファイル名 | プロファイル名を変更 |
| ❷ | 職業 + キャラクター名 | ドロップダウンで職業を選択しキャラクター名を入力。各キャラクターに個別の職業を割り当て。 |
| ❸ | キャラクター追加 | プロファイルに別のキャラクター名を追加（「追加」ボタン） |
| ❹ | タブで使用 | オン：複数タブのレイアウトで使用可能。オフ：専用ウィンドウでのみ開きます。 |
| ❺ | 保存 | 変更を適用 |
| ❻ | プロファイルをコピー | すべての設定を含むプロファイルのコピーを作成 |
| ❼ | 削除 | プロファイルを完全に削除 |
| ❽ | 閉じる | ダイアログを閉じる |

タブモードとウィンドウモードの両方でプロファイルを使用するには、❻ でコピーし、モードごとに1つのコピーを使用します。

**ステップ 5 — キャラクター付きプロファイルリスト：**

設定済みのプロファイルはキャラクター名と職業アイコンとともにリストに表示されます：

![説明](create_profil/create_profil_5_jp.png)

- 各キャラクターはプロファイル名の下に職業アイコン付きバッジとして表示されます。
- ヘッダーの職業フィルターとキャラクター名検索は、すべてのプロファイルのすべてのキャラクターを検索します。
- Killfeed などのプラグインは保存されたキャラクター名をドロップダウンで使用します。

プロファイルはいくつでも作成可能。各プロファイルは独立した Flyff セッションを保存。
ゲーム内設定はブラウザのように他セッションへ共有されない。

**プロファイルのエクスポート/インポート：**

![small](create_profil/create_profil_6.png)

| 番号 | 要素 | 説明 |
|------|------|------|
| ❶ | エクスポート | プロファイルを `.flyffprofile` ファイルとして保存 |
| ❷ | インポート | `.flyffprofile` ファイルを読み込み新しいプロファイルを作成 |

エクスポートされたファイルには以下が含まれます：

- プロファイルメタデータ（名前、職業、設定）
- Electron セッション Cookie（ログインデータ）
- localStorage データ（ゲーム設定）

バックアップやPC間の移行が可能です。
:::

:::accordion[レイアウトを作成]

**ステップ 1 — レイアウトを開始：**

タブが有効なプロファイルで **「プレイ」** をクリックします。

![説明](create_layout/create_layout_1_jp.png)

**ステップ 2 — グリッドを選択：**

希望するグリッドを選択します。ホバー時に右側に **ASCIIプレビュー** が表示されます。

![説明](create_layout/create_layout_2.png)

*対称レイアウト：*
- **1×1** — 単一ウィンドウ
- **1×2 / 2×1** — 2つのウィンドウ横並び / 縦並び
- **1×3 / 3×1** — 3つのウィンドウ横並び / 縦並び
- **1×4 / 4×1** — 4つのウィンドウ横並び / 縦並び
- **2×2** — 4つのウィンドウグリッド
- **3+2** — 上に3つ、下に2つ
- **2×3** — 6つのウィンドウグリッド
- **4+3** — 上に4つ、下に3つ
- **2×4** — 8つのウィンドウグリッド

*非対称レイアウト：*
- **1+2 →** — メインウィンドウ左、サブ2つ右
- **1+3 →** — メインウィンドウ左、サブ3つ右
- **1+2 ↓** — メインウィンドウ上、サブ2つ下
- **1+3 ↓** — メインウィンドウ上、サブ3つ下

非対称レイアウトではタブバーに **スライダー** が表示され、分割比率を調整できます（最小20% / 最大80%）。

![small](create_layout/create_layout_slider.png)

**ステップ 3 — プロファイルを割り当て：**

各セルにプロファイルを割り当てます。不要なセルは空のままにできます。

![説明](create_layout/create_layout_3_jp.png)

| 番号 | 要素 | 説明 |
|------|------|------|
| ❶ | グリッドセル | 選択したグリッドのセルを表示。セルをクリックして下のリストからプロファイルを割り当て。 |
| ❷ | プロファイルリスト | タブが有効な全プロファイル。クリックして選択セルに割り当て。 |
| ❸ | 次へ | 割り当てを確定し、割り当てたプロファイルでレイアウトを起動します。 |

**ステップ 4 — レイアウトを保存：**

画像で示されたボタン（タイトルバー内）で保存ダイアログを開きます。

![説明](create_layout/create_layout_4.png)

レイアウト名を入力し **「保存」** をクリック。

![説明](create_layout/create_layout_5_jp.png)

**ステップ 5 — ランチャーのレイアウトカード：**

保存されたレイアウトはプロファイルリストにカードとして表示されます：

![説明](create_layout/create_layout_6_jp.png)

- カードには **レイアウト名**、**プロファイル数**、**グリッドのミニチュア** が表示されます。
- **「プレイ」** でレイアウト全体を起動。
- **歯車アイコン** でレイアウト設定（名前、割り当て、グリッド）を開きます。

**関連設定**（設定 / レイアウト）：
- **Grid-Tabsを順次読み込み** — タブを同時ではなく順番に起動
- **変更時にレイアウトを更新** — レイアウトの変更を自動保存
- **アクティブなグリッドビューをハイライト** — 現在フォーカスされているタブを視覚的に強調
- **レイアウトのタブ表示** — ランチャーでのレイアウトタブの表示モード
- **レイアウト遅延** — タブ切り替え時の遅延時間

**関連ホットキー**（設定 / ホットキー）：
- **前のタブ** / **次のタブ** — タブを切り替え
- **次のウィンドウ** — 開いているウィンドウ間でフォーカスを切り替え
- **タブバー表示切替** — セッションウィンドウのタブバーを表示/非表示

**マルチウィンドウ：**

レイアウト以外にも複数の独立したセッションウィンドウを並行して開くことができます。セッションがアクティブな状態でプロファイルを開くと、現在のウィンドウに追加するか新しいウィンドウを作成するか尋ねられます。
:::

:::accordion[ホットキー]

ホットキーは、ゲームウィンドウがアクティブな状態でも動作する自由に割り当て可能なキーの組み合わせ（2～3キー）です。

**設定：**
- **設定 → ホットキー**を開きます。
- アクションの横にあるバッジをクリックして、希望のキーの組み合わせを押します。
- 競合は自動的に検出・表示されます。

![説明](hotkeys/hotkeys_settings_de.png)

**利用可能なアクション：**

| アクション | 説明 |
|-----------|------|
| オーバーレイ切替 | すべてのオーバーレイを表示/非表示 |
| サイドパネル切替 | サイドパネルを開く/閉じる |
| タブバー切替 | セッションウィンドウのタブバーを表示/非表示 |
| 前のタブ | 前のタブに切り替え |
| 次のタブ | 次のタブに切り替え |
| 次のウィンドウ | 開いているウィンドウ間でフォーカスを切り替え |
| CDタイマーリセット | すべてのCDタイマーを00:00に設定（キー入力待ち） |
| スクリーンショット | アクティブウィンドウのスクリーンショットを保存 |
| FCoins計算機 | FCoins計算機を開く |
| ショッピングリスト | プレミアムショッピングリストを開く |

設定済みのホットキーは、タブバーの**キーボードアイコン**からいつでも確認できます。

![説明](hotkeys/hotkeys_menu_de.png)
:::

:::accordion[データパスと永続化 (Windows)]

ユーザーデータは既定で `%APPDATA%/Flyff-U-Launcher/`（Electron `userData`）に保存。重要なファイル/フォルダ：

| 機能/ファイル                | 目的                                      | `%APPDATA%/Flyff-U-Launcher` からの相対パス |
|------------------------------|-------------------------------------------|---------------------------------------------|
| API-Fetch データとアイコン    | プラグイン用の生データ/アイコン（アイテム・モンスター等） | `api_fetch/<endpoint>/...`                  |

| プロファイル                  | ランチャープロファイル（名前・職業・フラグ） | `profiles.json`                             |
| レイアウト                    | タブ用グリッドレイアウト                  | `tabLayouts.json`                           |
| ROI キャリブレーション        | OCR/Killfeed 用 ROI 定義                  | `rois.json`                                 |
| OCR タイマー                  | OCR サンプリングレート（Killfeed/CD-Timer）| `ocr-timers.json`                           |
| プラグイン設定                | プラグインごとの設定（killfeed, cd-timer 等） | `plugin-data/<pluginId>/settings.json`      |

:::accordion[Killfeed]
- OCR でリアルタイムにキルと経験値を追跡。
- モンスター情報表示に必要な API-Fetch："Monster"。

**機能:**
- OCR によるキル検知（EXP 変化を自動検出）
- セッション/累積統計（キル数、EXP、キル/時、EXP/時 など）
- ゲーム画面に直接表示されるオーバーレイバッジ

**注意:**
- 現在は 1v1 レベリングのみ対応。
- 今後 AOE への拡張、モンスターグループやボスごとのキル追跡を予定。

**セットアップ:**

1. **未実施なら：API データをダウンロード**
   - プラグイン [API-Fetch](action:openPlugin:api-fetch) を開き、エンドポイント **"Monster"** を選択。
   - ダウンロードを開始。モンスターEXP表でキルを検証するのに必要。  
     （API-Fetch ドキュメント参照）
2. **プラグインを有効化**
   - ランチャーのプラグイン設定で **Killfeed** をオンに。  

3. **OCR 領域をキャリブレーション**（プロファイルごとに一度）
   - ランチャーから「剣ボタン」を押してゲームウィンドウを起動。  
   - サイドパネルで ROI キャリブレーションを開く。
   - ゲーム内の次の表示を囲む：
     - **EXP%** – 経験値表示
     - **Level** – レベル表示
     - **Character name** – キャラクター名
   - 保存すると各プロファイルに記録され、再設定不要。  
   - 左クリックで ROI をドラッグ。
   - 1 つ置いたら TAB で次を選択。  
   - Killfeed 用に設定：LVL, NAME, EXP, ENEMY（敵レベル）, ENEMY HP
   - 「Schließen」または ESC で終了。  
   - 描画後も微調整可能。  
   - 認識値はサイドパネルでライブ表示。
   - 重要なのは LVL と EXP。ENEMY/ENEMY HP は補助で、今後のため。
   - OCR のレベル表示が誤っていれば手動設定でき、手動値が優先。
   - EXP を OCR が一度誤検知した場合（例：キャラ切替）、手動で再設定可能。  
     EXP ルールが自動補正を阻害することがある。


4. **サイドパネルでプロファイルを選択**
   - サイドパネルの **Killfeed** タブを開く。
   - ドロップダウンから追跡するプロファイルを選択。  


5. **プレイする**
   - モンスターを倒すと OCR が EXP 変化を検出。
   - キルと統計がオーバーレイとサイドパネルに自動表示。

**サイドパネル:**
- 個別バッジのオン/オフ（キル/セッション、EXP/時、レベルアップまでのキル数など）。
- オーバーレイスケールを調整（0.6x–1.6x）。
- バッジを表示する行数を選択。
- Reset ボタンでセッション統計をリセット。
- 各セッションのデータはローカル保存。


- 検出されたキルはサイドパネルに表示され、永続保存されます。
- 保存先はプロファイルごとの AppData 配下 CSV ファイルです：
  - `user/plugin-data/killfeed/history/<profile-id>/daily/YYYY-MM-DD.csv`（単発キルの明細）
  - `user/plugin-data/killfeed/history/<profile-id>/history.csv`（日次サマリー）
- モンスター追跡アコーディオンには、各ランクごとに `Kills` ボタンがあります。
- `Kills` を押すと、選択したランクの単発キルを一覧表示します。


- 一覧表示では単発キルを削除できます（`Delete` -> `Confirm`）。
- 削除すると、サイドパネル表示と Killfeed 履歴ファイル（`daily/YYYY-MM-DD.csv` と `history.csv`）が即時更新されます。



**キル判定ルール:**
以下すべて満たすとキルとしてカウント：
- レベルが変化していない（レベルアップ/ダウンなし）。
- EXP が 0.001% 超増加（イプシロン閾値）。
- EXP ジャンプが 40% 以下（サスペクト閾値）。超えると「疑わしい」として除外。
- 直近 1500 ms 内に敵 HP バーを検出。HP バーなしの場合は前回キルから 2250 ms 以上で許可。
- API-Fetch のモンスターデータがある場合：EXP 増加が期待値の 10%〜10 倍の範囲内。外れると OCR エラーとして除外。

**却下される EXP 変化:**
- レベルアップ/ダウン：カウントなし。
- EXP 減少：無視（OCR ノイズ）。
- EXP ジャンプが 40% 超：疑わしいとして不採用。
- HP バーなし かつ 前回キルから 2250 ms 未満：カウントなし。

**備考:**
- キル検知には OCR が有効である必要があります。
- キル/時などの統計は 5 分のローリングウィンドウで算出。
:::

:::accordion[クエストガイド]
- レベル、地域、タイプでフィルタリングされた利用可能なクエストを表示 — チェーン表示とプロファイルごとの進捗追跡付き。
- 必要なAPI-Fetch: **Quest**、**NPC**、**Monster**、**Item**

**設定：**
1. **Quest Guide**プラグインが有効であることを確認します。
2. API-Fetchで必要なAPIデータをダウンロードします（Quest、NPC、Monster、Item）。
3. サイドパネルで**Quest Guide**タブを選択します。

**フィルターと検索：**
- **検索フィールド** — クエスト名、NPC、またはアイテムでフィルタリング
- **レベルモード：**
  - *OCR ±* — 現在OCRで検出されたレベルに一致するクエストを表示（調整可能な許容範囲、デフォルト: ±5）
  - *手動* — レベルと許容範囲を手動で入力
  - *最小–最大* — 固定のレベル範囲を設定（デフォルト: 1–30）
- **地域** — 表示を特定のゲーム地域に制限
- **タイプフィルター** — 全て / チェーン / デイリー / リピート / カテゴリ
- **サブカテゴリ** — リピートクエスト用: ペット、コレクション、モンスターハント、配達、その他

**進捗追跡：**
- クエストを完了としてマーク — 進捗はプロファイルごとに保存
- 「完了を表示」チェックボックスで表示/非表示
- 「利用不可を表示」チェックボックスで表示/非表示
- リセットボタンで進捗をリセット

**統計バー：**
合計、利用可能、完了したクエストの数を一目で表示します。

**クエストマップ：**
- サイドパネルのマップボタンでクエストの場所を表示するインタラクティブマップを開きます。

## ツール

ツールはホットキー、またはタブバーの星メニューから開けます。

:::accordion[Fcoin <-> Penya]

![説明](tools/fcoin_zu_penya/fcoin_zu_penya_1.png)
- FCoins と Penya を相互換算。
- 現在の Penya/FCoin レートを入力。レートは保存され次回自動ロード。
- FCoin 量または Penya 結果を変えると双方向に即計算。

![説明](tools/fcoin_zu_penya/fcoin_zu_penya_2.png)

:::

:::accordion[プレミアム買い物リスト]
- プレミアムショップ購入の計画ツール。FCoin 購入前の必要量試算に便利。ポップアップを許可しておくこと。
- 必要条件：API-Fetch エンドポイント **"Item"**（アイコン含む）。これが無いと検索結果は空。
![説明](tools/premium_shopping_list/premium_shopping_list_1.png)
- 使い方：
  1. 星メニューでツールを開き、検索欄にアイテム名を入力。
  2. 結果リスト（最大 20 件）にアイコン・名前・カテゴリが表示；**"+ Add"** で追加または数量増。  
  ![説明](tools/premium_shopping_list/premium_shopping_list_2.png)
  3. リストで価格（FCoins）と数量を設定。価格はフォーカスが外れた時に保存され、次回の検索で自動入力。
  4. チェックボックスで購入済み/完了をマーク、「X」で削除。
  5. 下部バーに全エントリの合計（`価格 × 数量`）を FCoins で表示。
- 保存：価格はランチャーデータフォルダに永続化（`%APPDATA%/Flyff-U-Launcher/item-prices.json`）。リスト自体はセッションごとにリセット。

:::

:::accordion[アップグレード費用計算機]

+0から+10までのアイテムアップグレードの予想費用を計算 — 必要な素材、試行回数、異なる保護システムの比較を含みます。

![説明](tools/upgrade_cost_calc/upgrade_cost_calc_1.png)

**設定：**

- **ダイス種類：** Powerdice 4/6（標準）または Powerdice 12（成功率向上）
- **レベルから / レベルまで：** アップグレード範囲を設定（例：+3 → +7）
- **モード：**
  - **比較** – 両方の保護システムのコストを並べて表示
  - **S-Protect** – 通常の S-Protect スクロールで計算
  - **S-Protect (Low)** – より安価な Low S-Protect スクロールで計算

**素材価格：**

「素材」で以下のアイテムの現在の市場価格を設定できます：
- 鉱物
- Eron
- S-Protect
- Low S-Protect
- Powerdice 4、6、12

「所持」チェックボックスで素材を費用計算から除外できます。

![説明](tools/upgrade_cost_calc/upgrade_cost_calc_2.png)

**結果：**

「計算」をクリックすると、各アップグレードレベルの詳細な表が表示されます：

| 列 | 意味 |
|----|------|
| レベル | 目標アップグレードレベル |
| 確率 | 成功率（パーセント） |
| 試行回数 | 予想試行回数 |
| 鉱物 | 必要な鉱物 |
| Eron | 必要なエロン |
| Penya | Penya費用 |
| 保護スクロール | 必要な保護スクロール |
| 合計費用 | 全費用のPenya合計 |

![説明](tools/upgrade_cost_calc/upgrade_cost_calc_3.png)

比較モードでは、両方の保護システム（S-Protect vs. S-Protect Low）が並べて表示されます。より安いオプションは緑色でハイライトされます。

**保存：** 価格と設定は自動的に保存されます（`%APPDATA%/Flyff-U-Launcher/user/tools/upgrades/upgrade_cost_calc.json`）。

:::

:::accordion[お知らせ]

ランチャーの右パネルに開発者からのメッセージが表示されます — アプリの更新は不要です。例：既知のバグ、現在の開発状況、計画中の機能。表示はドイツ語と英語で利用可能で、設定で無効にできます。

![説明](announcements/announcements_de.png)
:::

:::accordion[メッセージとエラーログ]

タブバーの**ログアイコン**をクリックすると、エラーログを含む別ウィンドウが開きます。

**機能：**
- すべての警告とエラーメッセージをタイムスタンプ付きで表示: `[HH:MM:SS] [レベル] [モジュール] メッセージ`
- **削除** — すべてのログエントリを削除
- **保存** — ログを`.txt`ファイルとしてエクスポート（`user/logs/`に保存）
- **メッセージ送信** — ログを開発者（Discord）に直接送信
  - オプション：説明とゲーム内/Discord名を追加
  - 誤って複数回送信することを防ぐ60秒のクールダウン

![説明](logs/logs_window_de.png)
:::

:::accordion[アップデート確認とバージョンロールバック]

**自動アップデート：**
- ランチャーは起動時に新しいバージョンが利用可能かどうかを確認します（設定で構成可能）。
- アップデートが利用可能な場合、ダウンロードオプション付きのダイアログが表示されます。
- ダウンロード中、進捗がパーセントバーとして表示されます。
- ダウンロード後、次回の再起動時にアップデートがインストールされます。

**手動確認：**
- **設定 → 動作**に**「今すぐ確認」**ボタンがあります。

**バージョンロールバック：**
- 古いランチャーバージョン（3.0.5以降）は設定から直接インストールできます。
- ドロップダウンに日付と現在のバージョンマーカー付きで利用可能なすべてのGitHubリリースが表示されます。
- バージョンを選択すると、ダウンロードされ再起動時にインストールされます。

![説明](settings/settings_update_de.png)
:::

:::accordion[RAM表示]

**設定 → 表示 → 「RAM使用量を表示」**でタブバーにメモリ表示を有効にできます。

**機能：**
- 合計メモリ使用量をMBで表示します。
- クリックすると詳細な内訳が開きます：
  - プロファイルごとのメモリ使用量
  - プラグインのメモリ使用量（共有のため推定値）
  - システムオーバーヘッド（ランチャー + OCR）

![説明](ram/ram_display_de.png)
:::
