## 🆕 Версия 3.1.0

### ✨ Новые функции

**Новые типы макетов**
- Вертикальные макеты: 2x1, 3x1, 4x1 (окна друг над другом)
- Асимметричные макеты: главное окно + 2–3 боковых окна справа (`main-r2`, `main-r3`) или снизу (`main-b2`, `main-b3`)
- Разделение асимметричных макетов настраивается ползунком (мин. 20% / макс. 80%)
- Выбор макета с ASCII-предпросмотром: при наведении отображается диаграмма макета

**Экспорт/Импорт профилей**
- Экспорт и импорт профилей в формате `.flyffprofile`
- Включает метаданные профиля, cookies сессии Electron и данные localStorage
- Позволяет создавать резервные копии и переносить между компьютерами

**Имена персонажей и классы для каждого персонажа**
- Имена и классы для каждого персонажа в профиле — отображение в виде бейджей с иконкой класса в списке профилей, с возможностью фильтрации и выбора в плагинах через выпадающий список

**Объявления лаунчера**
- Новый раздел в правой панели показывает сообщения от разработчика без обновления приложения — например, известные ошибки, текущие разработки или планируемые функции; доступен на немецком и английском языках, отключается в настройках
- Открытые профили в правой панели можно сворачивать и разворачивать

**Настройка шрифта**
- Новая настройка «Шрифт для оверлеев и UI» в настройках клиента — доступные шрифты: Josefin Sans, Roboto, Open Sans, Lato, Montserrat, Raleway, Nunito, Ubuntu, Cinzel; шрифт применяется к оверлеям лаунчера и DOM-элементам UI в игре

**Настройка размера шрифта**
- Новая настройка «Размер шрифта лаунчера»: масштабирование текста в окне лаунчера (75–150%), не влияет на саму игру

**Журнал ошибок и сообщение разработчику**
- Окно логов перемещено из боковой панели в панель вкладок — позволяет просматривать, сохранять и удалять журналы ошибок, а также отправлять сообщение разработчику (отображаемые ошибки прилагаются); 60-секундный кулдаун

**Плагин Quest Guide**
- Новый плагин в боковой панели: показывает квесты, включая начального/конечного NPC, задание и награды с маркером на карте — требуются данные квестов, NPC, монстров и предметов через API-Fetch

**Единый калькулятор улучшений**
- Калькулятор улучшений расширен дополнительными расчётами для оружия, украшений, пирсинга брони, пирсинга оружия, Ultimate, включая Pity-систему, FWC и бонус события, а также уже выполненные попытки

**Подсказки UI и значки помощи**
- Все важные элементы управления в лаунчере имеют подсказки (на всех 8 языках)
- Значки помощи (?) для сложных функций: имя профиля, режим вкладок/окон, имена персонажей
- Подсказки для ширины/высоты лаунчера, фильтров, выбора макета и ячеек сетки

**Телеметрия**
- Необязательная анонимная статистика запуска (версия, ОС, случайный ID)
- Включена по умолчанию, без личных данных, можно отключить в любое время

**Проверка обновлений и откат версий**
- Новая настройка: автоматическая проверка обновлений при запуске (вкл./выкл.)
- Кнопка «Проверить сейчас» в настройках
- Откат версий: старые версии лаунчера (начиная с 3.0.5) можно установить прямо из настроек
- Выпадающий список со всеми доступными GitHub-релизами, включая дату и отметку текущей версии

### 🚀 Производительность

**Оптимизация системы OCR**
- Платформо-безопасный метод захвата экрана: `xwd` на Linux (без контакта с GPU), `capturePage()` на Win/Mac — предотвращает зависания GPU и фризы игры
- При ошибке захвата на Linux сканирование пропускается, а не замораживает игру
- Кэш хэшей пикселей: OCR пропускается, если кадр не изменился — снижает нагрузку CPU при статическом игровом контенте
- Пустые результаты OCR корректно кэшируются — нет лишних повторов Tesseract на неизменённых пикселях
- Глобальный лимит параллельности Tesseract (макс. 1 одновременно) — предотвращает голодание CPU для GPU-процесса
- In-Memory кэши для профилей, ROI-Store и ROI-Visibility-Store вместо частых чтений из БД

**Оптимизация оверлеев**
- Эффективный опрос оверлеев: минимизированы переключения прозрачности и уменьшены интервалы
- Linux: избежание ненужных циклов Show/Hide для прозрачных оверлеев

## 🆕 Версия 2.5.1

### 🆕 Новая функция: Giant Tracker
Отдельное окно в плагине Killfeed — собирает и визуализирует статистику убийств для **Giants**, **Violets** и **Bosses**.

**Вкладки фильтра**
- 5 вкладок: **Все** · **Giants** · **Violets** · **Bosses** · **Drops**
- **Bosses** — фильтрация по рангу `boss` (красная рамка карточки, отдельный стиль иконок)
- **Drops** — показывает только монстров с зафиксированными дропами, включая превью пула лута (топ-5 предметов по редкости) прямо в карточке

**Статистика убийств**
- Карточный вид с режимами Compact и Expanded
- Периоды: Сегодня, Неделя, Месяц, Год, Всего
- Информация о монстре: иконка, имя, уровень, элемент, ранг, HP, ATK

**Отслеживание дропов**
- Логирование дропов из пула лута монстра (с фильтром редкости)
- История дропов по каждому монстру: название предмета, значение счётчика убийств, метка времени
- Статистика: Ø убийств/дроп, убийств с последнего дропа

**Time to Kill (TTK)**
- Автоматически измеряет длительность боя с Giants, Violets и Bosses
- 10-секундный льготный период при снятии цели (баф, лечение и т.д.) — время паузы не включается в TTK
- Отпечаток имени монстра + max HP: цель надёжно распознаётся повторно
- Отображение: Последний TTK, Ø TTK, Самый быстрый
- Сохраняется в истории убийств (столбец CSV `TTK_ms`)

**Прочее**
- Сортировка по количеству убийств, имени или уровню
- Поле поиска для фильтрации по имени монстра
